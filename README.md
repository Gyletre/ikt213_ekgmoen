# ikt213_ekgmoen
Machine vision

Project uses an uv virtual environment, which can be created with `uv venv` 

If uv is not installed, it can be installed with `pip install uv`

Make sure uv is on PATH on windows.

To update requirements, use `uv sync`

To run project, run `uv run assignment_x/main.py`, where `x` is the wanted assignment to be run

Venv can also be updated by running an assignment in this way.
